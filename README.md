# notification-service
Notification micro service

# Installation Guide
npm install express
npm install -D typescript ts-node ts-node-dev
npm install -D @types/node
npm install -D @types/express
npx tsc --init
npm install sequelize sequelize-cli
npm install pg pg-hstore
npm install ioredis
npm install amqplib
npm install bullmq

=> BullMQ uses Redis for:
Email Queue
Webhook Queue
Retry Queue
Dead Letter Queue

npm install nodemailer
npm install -D @types/nodemailer
npm install zod
npm install jsonwebtoken
npm install -D @types/jsonwebtoken
npm install dotenv
npm install winston
npm install cors helmet compression (Security)
npm install -D @types/cors
npm install -D @types/compression
npm install morgan
npm install -D @types/morgan
npm install swagger-ui-express swagger-jsdoc
npm install -D @types/swagger-ui-express
npm install uuid
npm install axios
npm install express-rate-limit
npm install rate-limit-redis
npm install @godaddy/terminus (Health Checks)
npm install prom-client (Metrics (Prometheus))
npm install -D jest ts-jest (Testing)
npm install -D supertest
npm install -D @types/jest
npm install -D @types/supertest
